# Modulhandbuch Informatik, Hochschule Musterstadt (erfundenes Übungsbeispiel)

## Programmierung 1
- ECTS: 6, Semester: 1
- Prüfungsform: Klausur (90 Minuten)
- Inhalte: Variablen, Kontrollstrukturen, Funktionen, einfache Datenstrukturen

## Datenbanken 1
- ECTS: 5, Semester: 2
- Prüfungsform: Klausur (90 Minuten)
- Inhalte: Relationales Modell, SQL (SELECT, JOIN, Gruppierung), Normalisierung, Transaktionen

## Mathematik für Informatik
- ECTS: 6, Semester: 1
- Prüfungsform: Klausur (120 Minuten)
- Inhalte: Logik, Mengen, Relationen, lineare Algebra, Grundlagen der Kombinatorik

## Softwaretechnik
- ECTS: 5, Semester: 3
- Prüfungsform: Projektarbeit
- Inhalte: Vorgehensmodelle, Anforderungen, Entwurf, Tests, Versionsverwaltung

## Rechnernetze
- ECTS: 5, Semester: 4
- Prüfungsform: mündliche Prüfung (20 Minuten)
- Inhalte: Schichtenmodelle, IP, TCP, HTTP, einfache Netzwerksicherheit
